# TriView Smart Glove 🧤

AI-powered smart glove designed to assist visually impaired users by identifying clothing colors, fabrics, and patterns using AI and IoT technologies.

## Features
- Color Detection
- Fabric Recognition
- Gesture Recognition
- Audio Feedback
- BLE Connectivity
- AI Stylist
- Arabic & English Support

## Technologies
- Raspberry Pi 5
- Python
- TensorFlow
- React
- Supabase

## System Workflow
1. User touches clothing
2. Sensors collect data
3. AI analyzes the input
4. Audio feedback is generated
